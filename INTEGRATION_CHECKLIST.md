# Проверка интеграции — 23 сентября 2026

Рабочая папка объединена в один интерфейс `frontend/` с PHP API и SQLite.
Вход: `start.cmd` → http://127.0.0.1:8000/. Корневой HTML перенаправляет в UI.
Исходный ZIP и рабочая папка до изменений совпадали по содержимому (различались
только окончания строк). Исходный ZIP в Downloads не изменён.

## Выполнено

- [x] Удалены конфликт Git в главной странице и повреждённые Markdown-фрагменты
  в исходниках. Исключены устаревшие дубли JS/CSS в корне.
- [x] Все формы используют общий HTTP-клиент и реальные PHP endpoints.
- [x] UI → сохранённый черновик → AI-вопросы → ответы → карточка в SQLite.
- [x] Единый AI-поток для новых и совместимых endpoints, фактический provider,
  локальный fallback и обработка ошибочных ответов внешней модели.
- [x] Название, тема, потребность и формат взаимодействия редактируются.
- [x] Рейтинг и начисления по каждому полю приходят с сервера. Подтверждение,
  снятие подтверждения и сохранение текста пересчитывают результат.
- [x] Публикация с 0 баллов после явного просмотра; обязательны название и контекст.
- [x] Каталог, фильтры, отправка предложения, принятие двух команд, отклонение,
  обновление статуса в кабинете соответствующей команды.
- [x] Профиль команды повторно используется без создания дубля; есть PATCH.
- [x] Изменение подтверждённого поля снимает публикацию и уменьшает рейтинг.
- [x] Ошибки и тайм-ауты показываются в UI; введённые правки сохраняются.
- [x] БД и миграции переживают повторный запуск без сброса данных.
- [x] Router не выдаёт БД, ключи, исходные архивы и служебные скрипты по HTTP.
- [x] JSON-запросы проверяют Content-Type; wildcard CORS удалён.
- [x] Переносимый PHP настроен с PDO SQLite, cURL и доверенным CA bundle;
  проверка TLS-сертификатов включена.

Браузерный сценарий создаёт отдельную временную копию, публикует карточку с нулём
баллов, подтверждает контекст и данные (20 → 40), проверяет две команды и их
раздельные списки предложений. После снятия подтверждения контекста рейтинг
становится 20, публикация снимается. Проверены закрытые пути router и отсутствие
влияния `.env` на явно пустой `AI_API_KEY` в тестовом окружении.

Мобильные карточка и профиль дополнительно осмотрены визуально. Правки карточки
сохраняются после перезагрузки. Команды запуска проверок приведены в README.

## Границы проверки

Реальный платный запрос к модели не выполнялся: пользовательский API-ключ не
предоставлен. Без ключа сценарий работает с локальным помощником. Ответы внешней
модели, отказ и сбои транспорта проверены на тестовых данных.

Приложение остаётся локальным MVP без регистрации и разграничения прав.
Переключение роли и выбор профиля предназначены для демонстрации, а не заменяют
авторизацию перед публичным размещением.
