# IdeaFlow MVP

IdeaFlow — MVP платформы, где бизнес превращает свободное описание потребности в структурированную карточку задачи, оценивает её готовность и публикует в общий каталог. Команды изучают задачи, отправляют предложения, а бизнес вручную выбирает исполнителя.

## Возможности

- создание задачи из свободного описания;
- уточняющие вопросы для заполнения карточки;
- расчёт рейтинга готовности от 0 до 100;
- уровни готовности задачи;
- публикация карточки в каталог;
- профили команд и предложения по задачам;
- ручной выбор команды бизнесом;
- локальная ИИ-функция: анализ неполных полей и генерация уточняющих вопросов.

ИИ помогает только структурировать информацию. Он не добавляет неподтверждённые факты и не выбирает команду автоматически.

## Технологии

- HTML / CSS / JavaScript — интерфейс;
- PHP 8+ — серверная логика;
- SQLite — локальная база данных;
- PDO — безопасное подключение PHP к SQLite.
