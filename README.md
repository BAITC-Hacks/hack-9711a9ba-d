# AI Sana MVP

AI Sana — MVP платформы для связи бизнеса и команд: бизнес описывает потребность, уточняет её в диалоге с ИИ-помощником, формирует карточку с рейтингом готовности и публикует задачу в каталог. Команды просматривают каталог, отправляют предложения, а бизнес вручную выбирает исполнителя.

## Полный сценарий

1. Пользователь выбирает роль: «Я бизнес» или «Я команда».
2. Бизнес создаёт черновик задачи из короткого описания.
3. ИИ-помощник или локальная логика генерирует минимум три уточняющих вопроса.
4. Ответы превращаются в редактируемую карточку задачи.
5. После подтверждения каждого поля пересчитываются рейтинг и уровень готовности.
6. Бизнес публикует карточку в общий каталог.
7. Команда просматривает каталог, сортирует и фильтрует задачи.
8. Команда отправляет предложение: идея, план, ссылка на прототип и срок.
9. Бизнес сравнивает предложения и вручную выбирает команду.
10. Система показывает итог сценария.

Автоматический выбор команды запрещён: решение всегда принимает бизнес.

## Реализованный ИИ-помощник

`ai_helper.php` находится в корне проекта, PHP endpoints — в `api/`.
Генерация уточняющих вопросов, сборка карточки, внешний API с локальным fallback,
валидация и последовательность интеграции описаны в [AI_HELPER.md](AI_HELPER.md).
